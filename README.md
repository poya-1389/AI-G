# ربات هوش مصنوعی کاراکترمحور تلگرام

فقط ۶ فایل — همه‌چیز داخلشون هست.

| فایل | محتوا |
|---|---|
| `main.py` | راه‌اندازی ربات و اتصال همه‌ی دستورات |
| `database.py` | دیتابیس (کاربرها، کاراکترها، تاریخچه‌ی چت، تنظیمات) |
| `ai_clients.py` | اتصال به Gemini / DeepSeek / ChatGPT |
| `handlers.py` | همه‌ی دستورات کاربر، ساخت کاراکتر، و پنل ادمین |
| `requirements.txt` | کتابخانه‌های موردنیاز |
| `README.md` | همین راهنما |

## قابلیت‌ها
- ساخت کاراکتر توسط خود کاربر (`/newcharacter`) و سوییچ بینشون (`/characters`)
- انتخاب مدل هوش مصنوعی هر کاربر (`/model`)
- حافظه‌ی مکالمه به‌ازای هر کاربر+کاراکتر، با پاک‌سازی (`/reset`)
- سقف پیام روزانه برای کنترل هزینه
- پنل ادمین کامل با `/admin` (آمار، پیام همگانی، بن، تنظیمات کلی، عمومی‌کردن کاراکتر)

## مراحل راه‌اندازی (کاملاً از گوشی)

### ۱) گرفتن توکن ربات
به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` بزن، توکن رو کپی کن.

### ۲) گرفتن کلید Gemini (رایگان)
به [aistudio.google.com](https://aistudio.google.com) برو، با گوگل وارد شو، **Get API key** بزن.

### ۳) گرفتن آیدی عددی خودت (برای ادمین شدن)
به [@userinfobot](https://t.me/userinfobot) پیام بده.

### ۴) ساخت مخزن روی GitHub
یک ریپازیتوری بساز و این ۶ فایل رو یکی‌یکی با **Add file → Create new file** بساز (اسم فایل رو دقیقاً همون‌طور که هست بذار، مثلاً `main.py`).

### ۵) ساخت سرویس روی Render
به [render.com](https://render.com) برو، با گیت‌هابت وارد شو (نیاز به کارت بانکی نیست)، **New → Web Service** بزن و ریپازیتوری رو انتخاب کن.

تنظیمات:
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python main.py`
- **Plan:** Free

در بخش **Environment** این متغیرها رو اضافه کن:

```
BOT_TOKEN=توکن مرحله ۱
GEMINI_API_KEY=کلید مرحله ۲
ADMIN_IDS=آیدی عددی مرحله ۳
DEFAULT_MODEL=gemini
```

(اگه بعداً خواستی DeepSeek یا ChatGPT هم اضافه کنی: `DEEPSEEK_API_KEY` یا `OPENAI_API_KEY`)

روی **Deploy** بزن. بعد از اولین دیپلوی، یه آدرس بهت میده شبیه:
`https://your-app.onrender.com`

### ۶) فعال‌سازی Webhook
یه متغیر محیطی جدید اضافه کن:
```
WEBHOOK_URL=https://your-app.onrender.com
```
ذخیره کن، Render خودش دوباره دیپلوی می‌کنه. تمام! برو توی تلگرام به رباتت `/start` بزن.

## نکته‌ی مهم درباره‌ی حافظه
پلن رایگان Render دیسک موقتی داره — با ری‌استارت سرویس، دیتابیس ممکنه پاک بشه. برای تست کاملاً کافیه؛ وقتی جدی‌تر شد می‌تونیم دیتابیس رو به یه سرویس دائمی و رایگان (مثل Supabase) منتقل کنیم.

## دستورات ادمین
با اکانت ادمین `/admin` رو بفرست تا لیست کامل رو ببینی.
